Use this tool to search known files or directories in the workspace for text.

Literal search is the default, and regular expressions are available when you need more precise matching. Set ignore_case=true to match case-insensitively. You can narrow directory searches with include or exclude patterns, skip the search root's `.gitignore` entries with respect_gitignore=true (root `.gitignore` only), cap the returned matching lines with limit, and request surrounding context when nearby lines matter.

Treat the structured `match_count` and `matches` results as the source of truth for follow-up decisions. If you do not know where to search yet, use `glob` first.
