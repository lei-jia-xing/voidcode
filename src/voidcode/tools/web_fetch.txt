- Fetches content from a specified URL
- Takes a URL and optional format as input
- Fetches the URL content and converts it to the requested format
- Returns the content in text, markdown, or html format
- Use this tool when you need to retrieve and analyze web content from a known URL

Usage notes:
  - The URL must be a fully-formed valid http or https URL
  - No DNS/private-address preflight: localhost, private-network, and metadata endpoints may be fetched
  - Redirects are followed up to five times; responses are streamed with a 5 MiB size cap
  - The original requested URL is preserved in result provenance
  - Text output includes requested/final URLs, MIME, decoded charset, and the raw-response reference
  - Raw response bytes are retained in `source_artifact`; supported raster images use attachments, SVG stays text, and opaque formats such as PDF stay referenced bytes
  - Format options: "markdown" (default), "text", or "html"
  - This tool is read-only and does not modify any files
  - If the exact URL is unknown, use web_search or another available source to discover candidate URLs.
  - Large text outputs are capped by the runtime tool-output policy; when truncated, the full output is saved to a workspace-local reference path in the result metadata.
