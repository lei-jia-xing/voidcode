Dispatch the next instruction to a keep-alive delegated worker turn.

Arguments:
- `task_id`: background task id returned by `task`.
- `prompt`: non-empty next instruction for the worker.

Rules:
- Only the background task's parent session may call `steer_task`; a different session must be rejected.
- The task must have been created with `task(keep_alive=true, run_in_background=true)`.
- Steering is allowed only while the task is `idle` (`awaiting_steer`) or `interrupted` (a resumable breakpoint after runtime restart). A running task has a turn in flight and cannot be steered; there is no pipelining.
- After a steer turn, the worker parks as `idle` again unless it submits its final result, which completes the task.
- Use the returned status and `waiting_reason` to decide the next action. Do not dispatch another steer while the worker is running.
