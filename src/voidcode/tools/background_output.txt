Read a background task status or a bounded aggregate projection.

Selectors (provide exactly one):
- `task_id`: read one background task.
- `task_ids`: aggregate these explicit task ids (1–100, no duplicates).
- `parallel_group_id`: read the runtime-owned parallel group.

Semantics:
- Aggregate reads are scoped to the current runtime tool context's parent session. Do not guess or supply another owner.
- `block=false` (the default) returns the current snapshot immediately; it does not wait. Do not repeatedly poll this tool in a tight loop.
- Prefer the runtime completion reminder instead of checking a running task repeatedly. Use `block=true` only when intentionally waiting in the current turn.

- Blocking waits use `timeout` in milliseconds; `block=true` requires at least 1000ms.
- Do not read a running child transcript just to peek at intermediate progress. Use this surface for an intentional status/result retrieval.
- `full_session=true` applies only to a single `task_id`: it returns bounded child-session metadata and a transcript preview, controlled by `message_limit` (1–100). Child raw output is kept outside the active provider context.
- Aggregate selectors always return bounded per-task status/summary/error/structured-output projections and never child transcripts; `full_session` does not change that.
- Failed, cancelled, or interrupted tasks are outcomes to report. Do not retry automatically or loop; retry only when explicitly requested.
