Use this tool when you know the exact file you want to inspect inside the workspace.

It is best for reading UTF-8 text files directly, and it can also return images and PDFs as attachments. For text files, the result is line-numbered and starts from the top of the file by default.

Reading a directory returns a bounded tree (depth 2, 12 entries per directory, newest first) with file sizes and relative ages; empty directories are marked `(empty directory)` and any truncated branch says so. Use it to orient in an unfamiliar area before `glob`/`grep`.

Reading an archive lists or decodes members with `archive.ext:inner/path` syntax (stdlib zip and tar families only):
- `read(path="build.zip")` lists immediate children; files show `name (size)`, directories end with `/`.
- `read(path="build.tar.gz:src/main.py")` decodes one member as UTF-8 text and supports the usual offset/limit paging. A member that is not UTF-8 text returns a notice instead of bytes.
- Inner paths are normalised (`/` separators, `.` segments dropped) and `..` segments are refused.
- Paths like `x.rar`, `x.7z`, `x.iso`, `x.deb` need third-party codecs and are reported as unsupported rather than decoded.

If the file is large, continue reading it with a later offset instead of switching to shell commands. When you do not know the exact path yet, use `glob` first. When you need to search for text across a known file or directory target, use `grep` instead.

Internal documentation URLs:
- read(path="voidcode://tool/<name>") returns the on-demand documentation and JSON input schema for any runtime-registered tool, including tools that are not listed top-level (the discoverable set). Read the doc first, then execute the tool with invoke_tool.
- read(path="voidcode://rule/<name>") returns a bounded workspace rulebook entry. Rule names are safe slugs resolved only from the workspace catalog.
- read(path="voidcode://artifact/<id>") returns a bounded slice of a spilled tool-output artifact owned by the current session (for example, a truncated tool output). Use the offset and limit arguments to page through large artifacts.
- read(path="voidcode://transcript/<session_id>") returns a bounded, payload-stripped transcript (per event: sequence, event_type, source) of the current session or of a child session the current session spawned. Limit defaults to 20 events (clamped 1..100).
