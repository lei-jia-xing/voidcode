Use this tool when you know the exact file you want to inspect inside the workspace.

It is best for reading UTF-8 text files directly, and it can also return images and PDFs as attachments. For text files, the result is line-numbered and starts from the top of the file by default.

If the file is large, continue reading it with a later offset instead of switching to shell commands. When you do not know the exact path yet, use `glob` first. When you need to search for text across a known file or directory target, use `grep` instead.

This tool does not read directories.
Internal documentation URLs:
- read(path="voidcode://tool/<name>") returns the on-demand documentation and JSON input schema for any runtime-registered tool, including tools that are not listed top-level (the discoverable set). Read the doc first, then execute the tool with invoke_tool.
- read(path="voidcode://artifact/<id>") returns a bounded slice of a spilled tool-output artifact owned by the current session (for example, a truncated tool output). Use the offset and limit arguments to page through large artifacts.
