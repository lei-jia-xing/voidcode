- Search the web for external information and current references
- Supported providers: Exa (`EXA_API_KEY`), Tavily (`TAVILY_API_KEY`), Brave (`BRAVE_API_KEY`), DeepSeek (`DEEPSEEK_API_KEY`), TinyFish (`TINYFISH_API_KEY`), Jina (`JINA_API_KEY`), Kagi (`KAGI_API_KEY`), Firecrawl (`FIRECRAWL_API_KEY` or keyless), Kimi (`KIMI_SEARCH_API_KEY` or `MOONSHOT_SEARCH_API_KEY`), Parallel (`PARALLEL_API_KEY`), Synthetic (`SYNTHETIC_API_KEY`), SearXNG (`SEARXNG_ENDPOINT`), Startpage (HTML scrape, always available), and DuckDuckGo (HTML scrape, always available)
- Default fallback order: exa, tavily, brave, deepseek, tinyfish, jina, kagi, firecrawl, kimi, parallel, synthetic, searxng, startpage, duckduckgo
- Provider order can be customized via `VOIDCODE_WEB_SEARCH_ORDER` (comma-separated provider IDs)
- Providers can be excluded via `VOIDCODE_WEB_SEARCH_EXCLUDE` (comma-separated provider IDs)
- Sequentially tries available providers; the first provider returning non-empty results wins
- Returns ranked results with structured rank, title, URL, and snippet, plus source/fallback metadata visible in the result text
- No parseable results is an empty success; request failures across all available providers return an error
- Use this tool when you need information beyond the local repository or do not yet know the exact URL

Usage notes:
  - The query parameter is required
  - `numResults` defaults to 8 and is capped at 20
  - Use web_fetch when the exact URL is already known
  - Treat external search results as research leads, not repository truth
